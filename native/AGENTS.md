# Kotlin/Native tooling and tests

`native/` holds the Kotlin/Native modules that do not depend on LLVM (CLI, utils, binary options, ObjC/Swift export, commonizer) and the
compiler integration tests (`native.tests`).

For the module map, build and test commands, and pitfalls, see [kotlin-native/AGENTS.md](../kotlin-native/AGENTS.md).
