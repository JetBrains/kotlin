# Deprecating JDK 17

In future releases of Kotlin, running the compiler with a JDK older than 17
will result in a compilation error. If you are affected by it, consider upgrading your
runtime to at least JDK 17 or newer.

### Using Kotlin Gradle Plugin

Kotlin compilations inherit the JDK from the Gradle daemon that launches them,
so it is Gradle itself that needs to be run with JDK 17 to avoid the deprecation warning.

Gradle chooses its runtime JDK based on:

1. `-Dorg.gradle.java.home` system property on the command line, 
2. `org.gradle.java.home` Gradle property in `gradle.properties`,
3. `JAVA_HOME` environment variable,
4. `java` command on `PATH`.

> **Note.** Kotlin Gradle Plugin supports `jvmToolchain()`, but it doesn't affect the runtime
> JDK used for running Kotlin compilations. Rather, it sets the value of `-jdk-home` compiler option
> as well as the default value of `-jvm-target`.

> **Note.** Upgrading the runtime JDK does not require changing the values of `jvmToolchain()`
> and `jvmTarget`, which means the version of the generated bytecode remains unchanged too.

See the following links to learn more on:

1. [supported compiler options](https://kotlinlang.org/docs/compiler-reference.html),
1. [defining compiler options in Kotlin Gradle Plugin](https://kotlinlang.org/docs/gradle-compiler-options.html#how-to-define-options),
2. [using `jvmToolchain()`](https://kotlinlang.org/docs/gradle-configure-project.html#gradle-java-toolchains-support).

### Running Kotlin on the Command Line

`kotlinc` chooses its runtime JDK based on:

1. `JAVA_HOME` environment variable, 
2. `java` command on `PATH`.

> **Note.** The default value of `-jvm-target` is always `1.8`, so the generated bytecode
> version is not affected by the runtime JDK used during compilation.

> **Note.** If you wish the compilation classpath of your Kotlin code to remain unaffected,
> consider setting `-jdk-home` to the JDK used previously.

See the following links to learn more on:

1. [supported compiler options](https://kotlinlang.org/docs/compiler-reference.html).
